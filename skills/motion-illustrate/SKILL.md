# Motion-Illustrate : des images calées sur les mots

Concepts issus de la vidéo « 8 outils motion design » de Simon De Lima (oct. 2026). Skill rédigé de zéro, sans reprise de son contenu.

Pour chaque phrase de la narration, définit l'image qui l'accompagne et prépare le détourage des sujets.

## Procédure

1. **Découpage.** Découper la narration en unités de sens (une idée = un plan, 3-6 secondes par plan).
2. **Illustration par plan.** Pour chaque unité, choisir :
   - le type visuel : illustration, capture d'écran, vidéo d'ambiance, schéma, texte seul ;
   - l'action : ce qui bouge dans le plan (zoom, parallaxe, révélation) ;
   - le lien avec les mots : l'image montre exactement ce que la phrase dit, ni avant ni après.
3. **Détourage.** Pour les plans avec un sujet (personne, produit) : décrire le détourage (outil, plume ou IA), le fond de remplacement, et l'intégration (ombre portée, reflet) pour que le collage ne se voie pas.
4. **Cohérence.** Vérifier que tous les plans partagent le même style (palette, trait, grain) : un changement de style se remarque immédiatement.
5. **Storyboard.** Livrer le storyboard : tableau phrase / timecode / visuel / mouvement / note.

## Règle d'or

L'image ne décore pas, elle explique. Si un plan n'aide pas à comprendre la phrase, le remplacer par du texte animé ou le supprimer.
