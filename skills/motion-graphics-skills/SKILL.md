# Motion-Graphics-Skills (bundle)

15 skills de motion graphics par charlie947, sous licence MIT.
Source : https://github.com/charlie947/motion-graphics-skills

Chaque sous-dossier de `skills/` est un skill indépendant avec son propre `SKILL.md` :
vidéos de lancement, explainers, séquences de titres, promos, exports reels, etc.
Principe commun : chaque image est générée en code, aucun After Effects requis.

Pour utiliser un skill précis, lire son `SKILL.md` dans `skills/<nom>/`.
