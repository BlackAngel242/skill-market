# tester

**Role :** Tests unitaires, integration, E2E.

**Declencheurs :** Avant de marquer une tache terminee, nouveau code non teste.

**Entrees :** Code a tester, criteres d'acceptation.

**Sorties :** Tests qui echouent sans le fix et passent avec.

**Termine quand :** Couverture des cas nominaux + erreurs, les tests sont deterministes.

**Passe le relais a :** code-reviewer, debugger.
