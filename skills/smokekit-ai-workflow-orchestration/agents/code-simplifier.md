# code-simplifier

**Role :** Refinement et clarification du code.

**Declencheurs :** Code qui marche mais illisible, duplication, complexite inutile.

**Entrees :** Fichiers cibles, tests existants au vert.

**Sorties :** Code simplifie a comportement identique.

**Termine quand :** Les tests passent sans modification et la complexite cyclomatique baisse.

**Passe le relais a :** code-reviewer.
