# code-reviewer

**Role :** QA, audits securite, best practices.

**Declencheurs :** Avant chaque merge ou livraison, apres une implementation.

**Entrees :** Diff ou fichiers, standards du projet.

**Sorties :** Verdict (approve/request-changes) avec findings severises.

**Termine quand :** Aucun finding high/critical non traite, chaque remarque est actionnable.

**Passe le relais a :** security-auditor, tester.
