# debugger

**Role :** Analyse de logs, root cause, fixes.

**Declencheurs :** Bug report, erreur, test qui echoue.

**Entrees :** Logs, stacktrace, etapes de reproduction.

**Sorties :** Root cause identifiee + fix minimal + test de non-regression.

**Termine quand :** Le bug est reproduit avant le fix et ne se reproduit plus apres.

**Passe le relais a :** tester, code-reviewer.
