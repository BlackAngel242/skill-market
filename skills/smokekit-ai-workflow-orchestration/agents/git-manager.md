# git-manager

**Role :** Commits pro, branches, PRs.

**Declencheurs :** Fin de tache, besoin de PR, historique sale.

**Entrees :** Changements testes et relus.

**Sorties :** Commits conventionnels atomiques, PR decrite et liee aux issues.

**Termine quand :** Chaque commit compile et passe les tests ; la PR explique le pourquoi.

**Passe le relais a :** code-reviewer.
