# Claude-Motion (bundle)

Toolkit motion design pour agents codeurs, par whaleyxbt, sous licence MIT.
Source : https://github.com/whaleyxbt/claude-motion

4 skills inclus :

- `motion-design` : principes et recettes d'animation pour interfaces.
- `sound-design` : sound design des vidéos (musique, effets, mixage).
- `review-loop` : boucle de relecture et d'amélioration des rendus.
- `web-sims` : simulations web animées.

Pour utiliser un skill précis, lire son `SKILL.md` dans son dossier.
