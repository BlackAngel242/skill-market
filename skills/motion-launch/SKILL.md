# Motion-Launch : vidéo de lancement produit

Concepts issus de la vidéo « 8 outils motion design » de Simon De Lima (oct. 2026). Skill rédigé de zéro, sans reprise de son contenu.

Transforme la description d'un produit en dossier complet de vidéo de lancement, prêt à produire.

## Entrée

Le lien du produit, ou à défaut : nom, promesse principale, public cible, prix, 3 arguments clés.

## Procédure

1. **Angle.** Formuler la promesse en une phrase, du point de vue du public (« ce que ça change pour moi »). Écarter le jargon.
2. **Script.** Structure en 4 temps, phrases courtes (12 mots max) :
   - Accroche (0-5 s) : le problème, pas le produit.
   - Démonstration (3 scènes max) : une fonctionnalité = un bénéfice visible.
   - Preuve (témoignage, chiffre, garantie).
   - Appel à l'action : une seule action, URL ou consigne claire.
3. **Version typographique (défaut).** Pas de voix off humaine : le texte s'affiche en kinetic typography, rythmé sur la musique. Prévoir une version voix off seulement si demandée explicitement.
4. **Plan caméra.** Pour chaque scène : type de plan (large, détail, écran), mouvement (travelling, zoom, fixe), durée indicative.
5. **Étalonnage.** Définir la direction : palette (2-3 couleurs), contraste, température. Cohérence avec l'identité du produit.
6. **Musique et rythme.** Proposer 2-3 directions musicales (énergie, tempo) et caler les transitions sur les temps forts.

## Sortie

Un document structuré : angle, script complet avec timecodes, plan caméra scène par scène, direction étalonnage, pistes musicales, checklist de production. Chaque affirmation sur le produit doit être vraie ou marquée comme proposition.
