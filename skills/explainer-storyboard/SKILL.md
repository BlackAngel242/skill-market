# Explainer-Storyboard : le storyboard d'abord, l'animation ensuite

Concepts issus de la vidéo « 8 outils motion design » de Simon De Lima (oct. 2026). Skill rédigé de zéro, sans reprise de son contenu.

Règle centrale : **aucune animation ne commence avant un storyboard validé.** Le storyboard coûte des minutes, une animation ratée coûte des heures.

## Les 7 styles

1. **Whiteboard** : main qui dessine, idéal pour expliquer un processus étape par étape.
2. **Flat design** : formes simples et couleurs vives, le plus polyvalent.
3. **Kinetic typography** : le texte est l'image, parfait pour les concepts abstraits.
4. **Isométrique** : fausse 3D pour montrer des systèmes, des architectures.
5. **Personnages** : mascottes ou silhouettes pour raconter une histoire avec un héros.
6. **Screencast animé** : capture d'écran guidée, zooms et callouts, pour les tutos produit.
7. **Mixte photo/vidéo** : images réelles + éléments animés par-dessus, pour l'émotion et la preuve.

## Procédure

1. **Choisir le style.** Selon le sujet (processus → whiteboard, concept abstrait → kinetic typography, produit → screencast...) et le public. Un seul style par vidéo.
2. **Découper le script** en scènes (une idée = une scène, 5-10 s).
3. **Storyboard.** Pour chaque scène : description du visuel, texte/narration, mouvement prévu, durée. Format tableau ou cases dessinées.
4. **Valider le storyboard** avant d'animer : l'histoire se comprend-elle sans l'animation ? Si non, revoir le découpage, pas les effets.
5. **Animer** scène par scène, dans l'ordre du storyboard.

## Contrôle final

Regarder la vidéo sans le son : l'histoire reste-t-elle compréhensible ? Si oui, le storyboard a fait son travail.
